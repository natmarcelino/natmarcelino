## ⭐ Projeto principal: EventCampus

Plataforma completa de gestão de eventos acadêmicos, com app mobile, painel web e API REST, **publicada e em uso**.

- 🔐 Autenticação com **JWT**
- 📷 Check-in de presença por **QR Code**
- 📍 Validação de localização por **GPS (fórmula de Haversine)** para impedir fraude no check-in
- 🗂️ Ciclo de vida dos eventos, inscrições sem duplicidade e busca por categoria
- ⏱️ Controle de horas complementares e envio de certificados externos para aprovação
- ☁️ Deploy: API e painel no **Render**, banco no **Neon**, APK Android via **EAS**

**Stack:** Java · Spring Boot 3 · PostgreSQL 16 · React Native · Expo · HTML/CSS/JS

🔗 **[Acessar o painel web](https://eventcampus-web.onrender.com)**: na tela de login, use os botões de usuário de teste (senha `123456`)
> O servidor é gratuito, então o primeiro acesso pode levar alguns segundos.
